# Mobile tools and dictation corrections — 24 October 2026

Continues the owner's later 24 October requests on the existing development preview.

- Quick tasks is an in-app panel available from a small Today badge. It starts with today's unfinished tasks across lists; the user can choose all tasks or an individual list. Completion uses the existing task save/sync path. The selection uses the existing device-local task preferences. Background Google task refresh also refreshes the badge and panel.
- Form actions have short visible captions and full accessible names. Custom sheets enter the existing polished form presentation when pinned, saved as a sheet, saved as a reusable template or used to update one. Definitions, answers, existing notebook schema and reusable-template identities remain intact.
- Drawing uses SVG tool icons, an expandable wide thickness slider and the established shared stroke renderer. Voice memo recording has a red centre and metallic silver rim; active recording changes the centre to a stop square. Existing recording capture, persistence and microphone cleanup remain in place.
- Dictation replaces the selected range and offers Stop, Select phrase, Replace selection, Undo dictation and Done. Trusted typing stops recognition. Incoming results cannot overwrite manual changes, removed fields or another notebook. Undo is disabled after manual editing. The correction panel tracks the visual viewport when the on-screen keyboard changes. Recognition still uses the browser's SpeechRecognition API; unsupported browsers receive keyboard-microphone guidance. No new remote transcription service was introduced.
- Account locking and navigation dismiss dictation. Every new runtime module is included in the build and service-worker cache; cache `v1.7.5-mobile-and-dictation`, asset imports `0.4.4`.

Validation: syntax/build and all 104 existing tests passed; notebook/account browser smoke passed. Existing polished-form/drawing/reorder/deletion/template-preservation checks passed on desktop, iPad landscape, iPad portrait and mobile. New `scripts/mobile-and-dictation-smoke.mjs` verifies task filtering/completion/preferences, selected dictation replacement, undo, manual-edit protection, the expanded drawing slider, recording icon, pin/save presentation and reload persistence at those four sizes. Screenshots were inspected for the iPad and mobile finished forms, mobile task panel and mobile correction panel. The new smoke is included in CI.

Limits: no physical iPad or Apple Pencil, real microphone transcription or authenticated Google end-to-end test. Hardware Pencil double-tap remains unavailable in the browser app; this change does not add a native iPad bridge or an operating-system home-screen widget. Local broader cover regression hit the environment's single-process Chromium limitation when creating another browser context; the standard CI browser suite remains authoritative for that broader check.
