Quick Capture

Install this small companion app to open Dictate, Camera and Type straight into your Inbox.

Link it to the Samsung Side button

  1. Open this page in Chrome on your Galaxy phone.
  2. Tap ⋮ → Install app (or Add to Home screen if that is what Chrome offers).
  3. Open Settings → Advanced features → Side button → Double press → Open app.
  4. Select Unbound Quick Capture or Capture from the app list.

Samsung’s app list can vary by software version. If Capture is not listed, the installed web app is not exposed to the Side button on this phone; use the Capture home-screen icon as the direct shortcut. Your double press can be changed back to Camera at any time in Side button settings.
